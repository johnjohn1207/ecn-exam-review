圖解 1・高頻大題

數位憑證身分驗證原理（Digital Certificate Authentication）

【手寫考卷作答默寫骨架】
1. 角色定義：Supplicant（驗證者）、Verifier（被驗證者/伺服器）、CA（公正第三方憑證機構）。
2. 核心流程：
  • CA 簽發：Server 將其身分與公鑰送交 CA，CA 使用 CA 私鑰 簽署生成 X.509 數位憑證。
  • 憑證交付：Client 向 Server 發起連線，Server 傳回此數位憑證。
  • 數學驗證：Client 利用作業系統或瀏覽器預先安裝之 CA 公鑰 驗證簽章真偽。若通過，確信該公鑰確實隸屬該 Server。
  • 挑戰驗證：Client 以 Server 公鑰加密隨機亂數傳送，Server 必須用自己的 Server 私鑰 成功解密，證明其真實性。
3. 相比其他認證優勢：杜絕中間人攻擊（MITM）；無須事先預先共享密碼，適合全球網際網路與 HTTPS。
圖解 2・手繪必考大題

資安管理生命週期（Threat -> Plan -> Protect -> Respond）與四大規劃原則

【手寫考卷作答默寫骨架】
1. 核心因果循環：威脅環境（Threat）決定規劃方針（Plan）$ ightarrow$ 規劃方針落實於日常防護（Protect）$ ightarrow$ 防護遭突破觸發應變（Respond）$ ightarrow$ 應變檢討反饋（Feedback Loop）重新修正規劃方針。
2. Plan 內的四大原則必寫：
  • Risk Analysis（風險評估）：在威脅代價與防護預算間取得平衡。目標非消除全部風險，而是在經濟合理限度內減低風險。
  • Comprehensive Security（全面性防衛）：堵死所有可能被攻擊的入侵端點，不留死角。
  • Defense in Depth（縱深防禦）：架設多層獨立防護。任一防禦失效時，其餘防線仍能阻擋攻擊。
  • Least Permissions（最低權限）：嚴格限制每位使用者僅具備業務所需的最小存取授權。
圖解 3・網路架構題

階層式交換網路與 802.1w RSTP 破除迴圈 / 容錯備援原理

【手寫考卷作答默寫骨架】
1. 問題背景：在階層式網路中，單一路徑存在單點失效。若部署備援線路會形成「實體迴圈」，造成廣播風暴癱瘓全網。
2. RSTP（802.1w）解法：交換器彼此發送 BPDU，建立無迴圈樹狀結構，將備援埠置於 Discarding/Alternate 狀態。
3. 容錯機制：當主線路斷裂時，RSTP 在數百毫秒內自動將備援埠切換至 Forwarding 狀態，實現無縫容錯。
