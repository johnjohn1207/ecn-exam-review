# 國立中央大學《企業電腦網路》期中考全方位複習與題庫互動系統

> National Central University (NCU) Enterprise Computer Networks Midterm Exam Review & Interactive Question Bank

本專案為針對國立中央大學資管系陳奕明教授《企業電腦網路》期中考所打造之全方位線上複習、歷年考古題庫、手寫架構圖解與模擬測驗系統。

- **🚀 線上即時體驗平台（GitHub Pages）**：[https://johnjohn1207.github.io/ecn-exam-review/](https://johnjohn1207.github.io/ecn-exam-review/)
- **📖 本地離線使用**：直接下載或雙擊 `index.html` 即可於任何瀏覽器離線執行。

---

## 系統核心功能

1. **🔥 歷年考古題考點統計與考頻排行**
   - 橫跨 10 屆期中真題（971 至 1071 學年度），精確統計各主題出題次數與命題機率。
   - Top 1 考頻冠軍：`QoS & SLA`（10 年全勤，出題率 100%）。
   - Top 2 手繪大題：`資安管理循環與四大規劃原則`（出現 6 次，出題率 60%）。
   - 一鍵跳轉對應模組詳解。

2. **✍️ 考場手寫專用：5 大必畫架構圖與默寫骨架**
   - 內建高解析 SVG 互動繪圖與標準作答口訣：
     1. **數位憑證身分驗證時序流程圖**（Digital Certificate Authentication）
     2. **企業資安戰略封閉循環架構圖**（Threat $\rightarrow$ Plan $\rightarrow$ Protect $\rightarrow$ Respond）與四大規劃原則
     3. **階層式交換網路與 802.1w RSTP 破除迴圈 / 容錯備援圖**
     4. **通訊協定訊息通用語法結構圖**（Header, Data Field, Trailer）
     5. **SNMP 集中式網管架構圖**（Manager, Agent, MIB）
   - 提供「一鍵複製考場默寫骨架」功能，方便考前背誦。

3. **📖 五大講義各章精華重點庫（Ch01 ~ Ch05 全收錄）**
   - 深入剖析 5 份上課投影片講義（共 295 頁 PDF）：
     - **Ch01：Welcome to the Cloud**（Netflix & AWS 雲端生態系、虛擬化、訊息分割、Single Network vs. Internet）
     - **Ch02：Network Standards**（ARPANET/IMP、TCP 三向交握、訊息封裝、PCM 語音編碼、IoT 補充）
     - **Ch03：Network Security**（Target 百貨案、惡意程式分類、對稱/非對稱密碼學、SPI 與次世代防火牆 NGFW）
     - **Ch04：Network and Security Management**（QoS 五大指標、SLA 合約、流量高峰四解法、資安生命週期、SNMP/SDN）
     - **Ch05：Ethernet (802.3) LANs**（UTP 雙絞線、MMF/SMF 光纖、Switch Table、802.1w RSTP、802.1X 認證、VLAN）

4. **🎯 歷年風格超擬真模擬考場（51 道練習題）**
   - **題型一：名詞解釋對比題（18 組）**：IaaS/PaaS/SaaS、Frame/Packet、Virus/Worm/Trojan、SPI/NGFW、MMF/SMF、STP/RSTP 等。
   - **題型二：問答推導與計算題（8 題）**：Wi-Fi 熱點共享吞吐量計算、電波平方反比衰減計算、Target 百貨案全流程、SPI 狀態過濾、802.1X 交握、Switch Table 學習轉發追蹤、資安風險分析矩陣。
   - **題型三：高擬真英文是非題（25 題）**：全英文原文書風格是非題，即按即測，並提供繁體中文精闢錯因剖析。

5. **⚡ 歷年英文是非真題測驗（106 / 107 學年度）**
   - 考卷固定 20 題英文是非題（佔分 20%），提供即時作答與自動計分反饋。
